# Figures

This directory contains evaluation plots generated by `run_evaluation.py`.

## Generated Figures

### Model Evaluation
- `comparison_metrics.png` - Bar charts comparing ELBO, train/validation LL, MSE, R², and deviance across link functions
- `train_test_split.png` - Visualization of train/test data split (80/20)
- `rate_map_comparison.png` - Predicted firing rate maps for different link functions

### Predictive Performance
- `prediction_scatter.png` - Scatter plot of predicted vs. observed rates on test data
- `uncertainty_vs_error.png` - Relationship between posterior uncertainty and prediction error

### Link Function Comparisons
- `link_function_comparison.png` - Direct transformations g(f), expected rates, and uncertainty effects
- `link_function_gradients.png` - Gradients w.r.t. mean and variance for optimization

## Regenerating Figures

To regenerate all figures, run:
```bash
uv run python run_evaluation.py
```

All figures will be saved to this directory automatically.
